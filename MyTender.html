MyTenders Setup

Connect your Firebase Realtime Database to store and sync your tender data across any device.

One-time Firebase setup:
1. Go to console.firebase.google.com
2. Create a project → Realtime Database → Create database
3. In Rules tab, set ".read": true, ".write": true → Publish
4. Copy the Database URL and paste below
This is saved in your browser — you only enter it once.
